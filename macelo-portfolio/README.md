Portfólio pessoal focado em Desenvolvimento Back-end Java.

## Stack do site
- HTML5
- CSS3
- JavaScript
- Layout responsivo
- Sem dependências de framework

## Publicar no GitHub Pages
1. Crie um repositório público chamado `Macelo2266.github.io`.
2. Envie `index.html` e a pasta `assets`.
3. No GitHub, abra Settings → Pages.
4. Em Source, selecione `Deploy from a branch`.
5. Selecione `main` e `/ (root)`.
6. Salve e aguarde a publicação.

## Antes de publicar
- Troque os textos "Seu projeto principal", "Seu segundo projeto" e "Seu terceiro projeto" pelos seus projetos reais.
- Adicione seu e-mail na seção de contato.
- Se tiver portfólio/demo de algum projeto, substitua os links do GitHub.
- Não adicione tecnologias que você não domina ou não utilizou.
